Tab options for the djbod console

Seven treatments of the same four tabs, each drawn with the console's own colours in both themes. Everything below the tabs is the same mock Overview so only the tabs differ. Pick one, or name what to combine.

A · Segmented control what PR #64 does

One rounded track, the selected tab raised on the surface colour. Reads as a control rather than as navigation; a little heavy for four items.
