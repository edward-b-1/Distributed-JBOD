Status marks for the djbod console

The page marks pass, fail, and warning in many places: the nodes table, the health card, device states, verify results, the object list, logs. Today they are text glyphs from the font, which is why the check, the cross, and the black triangle do not match. Five drawn sets below, each shown in a nodes-table row, a health card, and the device states, in both themes. Every set uses the same four colours: green, red, amber, and grey for off or removed.
